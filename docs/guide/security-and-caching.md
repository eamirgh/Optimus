# Security & Caching

Image processing endpoints are common targets for Denial-of-Service (DoS) and memory exhaustion attacks. Optimus implements three layers of defense.

## 1. Cryptographic HMAC-SHA256 URL Signing

Every dynamic image URL generated by Optimus contains an HMAC-SHA256 signature (`s=...`) computed from the path, dimensions, quality, and fit options using your application secret.

If an attacker modifies `w=1280` to `w=9999` or crafts random URLs, Optimus rejects the request immediately with an HTTP `403 Forbidden` without loading or allocating memory for the image.

## 2. Dimension Whitelisting

Even with signing, you may want to limit the allowed dimension permutations. Optimus validates requested dimensions against a strict whitelist configured in `config/optimus.php`:

```php
'allowed_dimensions' => [
    [320, 240],
    [640, 480],
    [1280, 720],
    [1920, 1080],
],
```

Any request outside these bounds is rejected with HTTP `400 Bad Request`.

## 3. Thundering Herd Mitigation (Atomic Cache Locks)

When an image variant has not yet been rendered and hundreds of requests hit simultaneously (e.g., after a cache flush or social media spike), naive servers spawn hundreds of parallel resize tasks, exhausting server CPU and RAM.

Optimus utilizes atomic cache locks (`Cache::lock`):
1. The first worker acquires the lock for that specific image variant and begins processing.
2. Concurrent workers wait for the lock to release.
3. Once the first worker writes the result to disk, waiting workers read directly from disk without re-rendering.

## 4. Web Server Warm Cache Bypass (`try_files`)

When using local storage (`OPTIMUS_DISK=public`), Optimus writes generated images to `/public/optimus/`.

Configure Nginx to bypass PHP entirely for warm cache hits:

```nginx
location /optimus/ {
    try_files $uri /index.php?$query_string;
    expires 1y;
    add_header Cache-Control "public, max-age=31536000, immutable";
}
```

The first request renders and saves the file. Subsequent requests are served directly by Nginx at kernel wire speed.
